# Jhonn | Portafolio personal

¡Bienvenido a mi portafolio! Soy estudiante de Ingeniería en Computación en la Universidad San Francisco de Quito, ciclista y campeón nacional. Aquí comparto un poco de mi historia, mis intereses y los proyectos que he desarrollado durante mi aprendizaje.

## Sobre mí

Me gusta combinar dos mundos que me inspiran: el deporte y la tecnología. El ciclismo me ha enseñado disciplina, constancia y determinación; la programación me permite convertir ideas en experiencias digitales.

## Intereses

- **Ciclismo:** entreno y compito; he conseguido títulos en campeonatos nacionales.
- **Programación:** disfruto crear páginas web y videojuegos con HTML, CSS y JavaScript.
- **Tecnología:** me interesa explorar herramientas digitales y aprender cómo funcionan las aplicaciones y los servicios en línea.

## Proyectos

### Proyecto 1 — Velocity Run

Videojuego de plataformas donde el jugador corre, salta y se agacha para evitar obstáculos y recoger objetos.

- Aplicación publicada: https://jhonn16ax.github.io/proyecto/
- Repositorio: https://github.com/Jhonn16ax/proyecto
- Tecnologías: HTML, CSS y JavaScript.
- Publicación: GitHub Pages.
- Los movimientos y la lógica se ejecutan en el navegador; no utiliza una base de datos para guardar resultados.

### Proyecto 2 — Speed Rivals

Videojuego de carreras 2D para dos jugadores que se conectan desde distintos dispositivos.

- Aplicación publicada: https://proyecto12-kohl.vercel.app/
- Repositorio: https://github.com/Jhonn16ax/proyecto12
- Tecnologías: HTML, CSS, JavaScript, Supabase Realtime y Vercel.
- Supabase Realtime sincroniza a los jugadores. La tabla \`race_results\` guarda el ganador, la distancia, los nombres de los jugadores y la fecha de la carrera.
