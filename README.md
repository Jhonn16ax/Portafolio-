## Proyectos

### Velocity Run
Videojuego de plataformas para navegador. El jugador salta y se agacha para esquivar obstáculos y recoger objetos.

- Aplicación: https://jhonn16ax.github.io/proyecto/
- Repositorio: https://github.com/Jhonn16ax/proyecto
- Tecnologías: HTML, CSS y JavaScript.
- Publicación: GitHub Pages.
- La lógica del juego se ejecuta en el navegador. No utiliza una base de datos para guardar las partidas.

### Speed Rivals
Videojuego de carreras 2D para dos jugadores que se conectan desde dispositivos distintos.

- Aplicación: https://proyecto12-kohl.vercel.app/
- Repositorio: https://github.com/Jhonn16ax/proyecto12
- Tecnologías: HTML, CSS, JavaScript, Supabase Auth, Supabase Realtime y Supabase Database.
- Publicación: Vercel.
- Supabase Auth gestiona las cuentas; Realtime sincroniza el estado de los jugadores; `race_results` guarda los resultados con el identificador de cuenta `user_id`, y `race_leaderboard` mantiene la clasificación compartida.
