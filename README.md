## Proyectos

### 1. Velocity Run

Videojuego de plataformas en el que el jugador salta y se agacha para superar obstáculos y recoger objetos.

- **Aplicación:** https://jhonn16ax.github.io/proyecto/
- **Repositorio:** https://github.com/Jhonn16ax/proyecto
- **Tecnologías:** HTML, CSS y JavaScript.
- **Publicación:** GitHub Pages.
- **Funcionamiento:** la lógica del juego se ejecuta en el navegador. No utiliza una base de datos para guardar resultados.

### 2. Speed Rivals

Videojuego de carreras 2D para dos jugadores que pueden conectarse desde distintos dispositivos.

- **Aplicación:** https://proyecto12-kohl.vercel.app/
- **Repositorio:** https://github.com/Jhonn16ax/proyecto12
- **Tecnologías:** HTML, CSS, JavaScript, Supabase Realtime y Vercel.
- **Funcionamiento:** Supabase Realtime sincroniza el estado de los jugadores. La tabla \`race_results\` almacena el ganador, la distancia, los nombres de los jugadores y la fecha de la carrera.
